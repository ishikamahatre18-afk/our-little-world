# Our Little World

Act as an expert UI/UX designer and full-stack application developer.



Create a beautiful, premium, mobile-first couples relationship application called:



Between Us ❤️



Tagline: "Our Little World, Just You & Me."



The application should combine three visual styles:



1. Cute and romantic

2. Minimal and luxurious

3. Dreamy and aesthetic



DESIGN SYSTEM:



Use a sophisticated romantic color palette:



- Blush pink: #F8D7E3

- Soft lavender: #E9DDF8

- Warm cream: #FFF9F5

- Rose pink: #E78BA6

- Deep plum: #49354A



Use elegant typography, rounded cards, soft shadows, subtle gradients, delicate heart illustrations, and smooth animations.



The interface should look like a professionally designed premium mobile application.



Avoid childish graphics, cluttered layouts, and excessive animations.



PHASE 1 — BUILD THESE SCREENS:



1. Welcome Screen



- Beautiful animated heart illustration

- App name: Between Us

- Tagline: Our Little World, Just You & Me

- Get Started button

- Login button



2. Signup and Login



- Email and password authentication

- Google login only if it can be implemented using free services

- Forgot password option

- Elegant, mobile-friendly forms



3. Profile Setup



- Name

- Profile picture

- Birthday (optional)

- Relationship anniversary date



4. Connect With Partner



- Generate a unique invitation code

- Allow another user to enter the code

- Require both partners to approve the connection

- Display a romantic success animation



5. Home Dashboard



- Both partners' profile pictures

- Relationship days counter

- Anniversary countdown

- Daily romantic quote

- Today's relationship question

- Quick access to love letters and memories



6. Bottom Navigation



- Home

- Our Space

- Activities

- Memories

- Profile



TECHNOLOGY:



Use React, TypeScript, Tailwind CSS, and Supabase.



Make the application responsive and installable as a Progressive Web App.



Use only free services and open-source libraries.



IMPORTANT:



I am building this entirely on my Android phone and have a budget of ₹0.



Build the app in stages to conserve AI credits.



Do not implement premium subscriptions, paid AI APIs, or complex additional features yet.



Use real authentication and secure database access when Supabase is connected.



Do not pretend unfinished features are functional.



For this first step, focus on creating the complete visual design and navigation for the six screens.



After completing the initial interface, tell me what is working, what is still a placeholder, and what I need to do next.



Make the experience feel like a beautiful, private digital world created for two people in love.
